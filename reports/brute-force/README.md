# Brute Force Detection Reports

This folder contains exported reports generated from the Splunk detection for Windows brute-force authentication attempts.

## Detection

- **Detection Name:** Windows Brute Force Detection
- **Event ID:** 4625
- **SIEM:** Splunk Enterprise

## Files

| File | Description |
|------|-------------|
| Brute-Force-Detection.csv | Exported Splunk search results showing failed Windows authentication attempts used to validate the detection. |

## Purpose

These reports provide evidence that the SPL detection successfully identified repeated failed login attempts and can be used during detection validation and incident investigations.
