# Detection 006 – Scheduled Task Creation

## Objective

Detect newly created Windows scheduled tasks by monitoring Security Event ID 4698. Scheduled tasks may be abused to execute commands, establish persistence, or run malicious code under another security context.

---

## MITRE ATT&CK

| Tactic | Technique |
|---|---|
| Execution, Persistence, Privilege Escalation | T1053.005 – Scheduled Task/Job: Scheduled Task |

---

## Data Source

- Windows Security Event Log
- Event ID 4698
- Advanced Audit Policy: Other Object Access Events

---

## Detection Logic

Monitor Event ID 4698 and extract the account, task name, command, and arguments from the event message and embedded task XML.

Prioritize tasks that execute command interpreters, scripts, encoded commands, binaries in user-writable paths, or programs launched by unexpected users.

---

## Splunk Search

```spl
source="WinEventLog:Security" EventCode=4698
| rex field=Message "Account Name:\s+(?<AccountName>[^\r\n]+)"
| rex field=Message "Task Name:\s+(?<TaskName>[^\r\n]+)"
| rex field=Message "<Command>(?<Command>[^<]+)</Command>"
| rex field=Message "<Arguments>(?<Arguments>[^<]*)</Arguments>"
| table _time host AccountName TaskName Command Arguments
| sort -_time
```

---

## Audit Configuration

Enable scheduled-task creation auditing on the Windows endpoint:

```cmd
auditpol /set /subcategory:"Other Object Access Events" /success:enable /failure:enable
```

Confirm the setting:

```cmd
auditpol /get /subcategory:"Other Object Access Events"
```

---

## Test Procedure

1. Open Command Prompt as Administrator on the Windows test endpoint.
2. Enable the required audit policy.
3. Create a benign scheduled task:

   ```cmd
   schtasks /create /tn "SOC-Test-Task" /tr "cmd.exe /c exit" /sc ONCE /st 23:59 /f
   ```

4. Run the Splunk search and confirm Event ID 4698 is present.
5. Record the account, task name, command, arguments, host, and timestamp.
6. Remove the test task:

   ```cmd
   schtasks /delete /tn "SOC-Test-Task" /f
   ```

## Validated Result

The detection was validated in the Enterprise Splunk SOC Lab with the following observed values:

- Event ID: 4698
- Host: WIN-11
- Account: soctest
- Task name: `\SOC-Test-Task`
- Test action: `cmd.exe /c exit`
- Event message: A scheduled task was created

---

## Investigation Guidance

1. Determine whether the task was created through an approved administrative or software-management process.
2. Review the task name, author, triggers, command, arguments, working directory, and security context.
3. Flag command interpreters, PowerShell, script hosts, encoded commands, and user-writable execution paths.
4. Correlate the event with process creation, logon, PowerShell, file-creation, and network activity.
5. Check whether the task was modified, executed, or deleted shortly after creation.
6. Escalate unauthorized or unexplained scheduled-task creation.

---

## False Positives

Legitimate Event ID 4698 activity may be generated by:

- Software installations and updates
- Enterprise management tools
- Backup and maintenance software
- Authorized administrators
- Security products

Baseline approved task names, creators, execution paths, and deployment windows to reduce noise.
