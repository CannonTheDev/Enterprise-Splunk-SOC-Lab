# Detection 005 – New Windows Service Installation

## Objective

Detect newly installed Windows services by monitoring System Event ID 7045. Attackers may create services to establish persistence, execute payloads, or move laterally between Windows systems.

---

## MITRE ATT&CK

| Tactic | Technique |
|---|---|
| Persistence, Privilege Escalation | T1543.003 – Create or Modify System Process: Windows Service |

---

## Data Source

- Windows System Event Log
- Service Control Manager
- Event ID 7045

---

## Detection Logic

Monitor Event ID 7045 for new service installations. Review the service name, executable path, start type, service type, account, destination host, and creation time.

Services that execute from user-writable directories, use command interpreters, reference unusual paths, or run as LocalSystem deserve additional scrutiny.

---

## Splunk Search

```spl
source="WinEventLog:System" EventCode=7045
| table _time host Service_Name Service_File_Name Service_Type Service_Start_Type Service_Account
| sort -_time
```

### Focused Validation Search

```spl
source="WinEventLog:System" EventCode=7045 Service_Name="SOC-Test-Service"
| table _time host Service_Name Service_File_Name Service_Type Service_Start_Type Service_Account
| sort -_time
```

---

## Test Procedure

1. Open Command Prompt as Administrator on the Windows test endpoint.
2. Create a benign test service:

   ```cmd
   sc.exe create SOC-Test-Service binPath= "C:\Windows\System32\cmd.exe /c exit" start= demand
   ```

3. Run the focused Splunk search and confirm Event ID 7045 is present.
4. Record the host, service name, binary path, service type, start type, account, and timestamp.
5. Remove the test service:

   ```cmd
   sc.exe delete SOC-Test-Service
   ```

---

## Validated Result

The detection was validated in the Enterprise Splunk SOC Lab with the following observed values:

- Host: WIN-11
- Service name: SOC-Test-Service
- Service file: `C:\Windows\System32\cmd.exe /c exit`
- Service type: user mode service
- Start type: demand start
- Service account: LocalSystem
- Event ID: 7045

---

## Investigation Guidance

1. Determine whether the service installation was authorized.
2. Validate the service name and executable path against approved software.
3. Check whether the binary resides in a temporary, user-profile, download, or other writable directory.
4. Review the service account and flag unexpected LocalSystem execution.
5. Correlate the event with process creation, authentication, PowerShell, SMB, and remote-service activity.
6. Collect and analyze the referenced executable when the service is suspicious.
7. Escalate unauthorized or unexplained service creation.

---

## False Positives

Legitimate Event ID 7045 activity may be generated by:

- Software and security-agent installations
- Splunk services and drivers
- VMware tools and drivers
- Windows updates
- Authorized administrative changes

Baseline approved service names, publishers, paths, and installation windows to reduce noise.

---

## Detection Status

Validated in the lab using a controlled Windows service creation event on WIN-11.
