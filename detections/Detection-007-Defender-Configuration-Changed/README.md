# Detection 007 – Microsoft Defender Configuration Changed

## Objective

Detect changes to Microsoft Defender Antivirus configuration by monitoring Defender Operational Event ID 5007. Attackers may modify Defender settings to reduce visibility, add exclusions, or impair endpoint protections.

---

## MITRE ATT&CK

| Tactic | Technique |
|---|---|
| Defense Evasion | T1562.001 – Impair Defenses: Disable or Modify Tools |

---

## Data Source

- Microsoft Defender Antivirus Operational log
- Event ID 5007
- Splunk source: `XmlWinEventLog:Microsoft-Windows-Windows Defender/Operational`

---

## Detection Logic

Monitor Event ID 5007 and extract the old and new configuration values from the XML event data. Review changes involving real-time protection, exclusions, behavior monitoring, cloud protection, PUA protection, or other security-sensitive Defender settings.

---

## Splunk Search

```spl
source="XmlWinEventLog:Microsoft-Windows-Windows Defender/Operational" EventCode=5007
| rex field=_raw "Old Value[^>]*>(?<OldValue>[^<]*)"
| rex field=_raw "New Value[^>]*>(?<NewValue>[^<]*)"
| table _time host OldValue NewValue
| sort -_time
```

### Suspicious-Change Focus

```spl
source="XmlWinEventLog:Microsoft-Windows-Windows Defender/Operational" EventCode=5007
| rex field=_raw "Old Value[^>]*>(?<OldValue>[^<]*)"
| rex field=_raw "New Value[^>]*>(?<NewValue>[^<]*)"
| search NewValue="*Disable*" OR NewValue="*Real-Time Protection*" OR NewValue="*Exclusions*" OR NewValue="*BehaviorMonitoring*" OR NewValue="*PUAProtection*"
| table _time host OldValue NewValue
| sort -_time
```

## Splunk Input Configuration

The Defender Operational channel was added to the Universal Forwarder configuration:

```ini
[WinEventLog://Microsoft-Windows-Windows Defender/Operational]
disabled = 0
renderXml = true
current_only = 0
start_from = oldest
```

---

## Validation Procedure

1. Confirm the Defender Operational log contains local events.
2. Add the Defender Operational channel to the Splunk Universal Forwarder inputs.
3. Restart the SplunkForwarder service.
4. Confirm Event ID 5007 events arrive in Splunk.
5. Run the detection search and verify that `OldValue` and `NewValue` are extracted from the XML.
6. Confirm Microsoft Defender real-time protection remains enabled after testing.

---

## Validated Result

The detection was validated in the Enterprise Splunk SOC Lab with the following observed values:

- Event ID: 5007
- Host: WIN-11
- Source: Microsoft Defender Antivirus Operational
- Extracted fields: OldValue and NewValue
- Observed activity: Microsoft Defender configuration changes

---

## Investigation Guidance

1. Identify the exact Defender setting that changed and compare the old and new values.
2. Determine whether the change was authorized through Group Policy, endpoint management, an update, or an administrator.
3. Prioritize changes that disable protections or add exclusions.
4. Correlate the event with PowerShell, process creation, registry, logon, and software-deployment telemetry.
5. Review the endpoint for suspicious files or processes that appeared near the configuration change.
6. Restore the approved Defender configuration and escalate unauthorized changes.

---

## False Positives

Legitimate Event ID 5007 activity may be generated by:

- Microsoft Defender platform and intelligence updates
- Windows startup and service initialization
- Group Policy or endpoint-management changes
- Authorized security administrators
- Software installation or maintenance

Reduce noise by baselining normal update activity and alerting more aggressively on security-sensitive keys and unexpected hosts.
