# Detection 008 – New Domain Account Created

## Objective

Detect newly created Active Directory user accounts by monitoring Windows Security Event ID 4720. Attackers may create domain accounts to establish persistence, maintain access, or prepare for privilege escalation.

---

## MITRE ATT&CK

| Tactic | Technique |
|---|---|
| Persistence | T1136.002 – Create Account: Domain Account |

---

## Data Source

- Windows Security Event Log
- Event ID 4720
- Active Directory domain controllers

---

## Detection Logic

Monitor Event ID 4720 and identify the subject account that performed the action and the newly created account. Review unexpected creators, unusual account names, after-hours activity, and accounts created outside approved identity-management processes.

---

## Splunk Search

```spl
source="WinEventLog:Security" EventCode=4720
| rex field=Message "Account Name:\s+(?<AccountName>[^\r\n]+)"
| rex field=Message "New Account:\s+Security ID:[^\r\n]+\s+Account Name:\s+(?<NewAccountName>[^\r\n]+)"
| table _time host AccountName NewAccountName
| sort -_time
```

### Focused Validation Search

```spl
source="WinEventLog:Security" EventCode=4720
| rex field=Message "Account Name:\s+(?<AccountName>[^\r\n]+)"
| rex field=Message "New Account:\s+Security ID:[^\r\n]+\s+Account Name:\s+(?<NewAccountName>[^\r\n]+)"
| search NewAccountName="SOC-Test-4720"
| table _time host AccountName NewAccountName
| sort -_time
```

---

## Test Procedure

1. Open Command Prompt as Administrator on a domain controller.
2. Create a controlled domain account:

   ```cmd
   net user SOC-Test-4720 "TempP@ssw0rd!4720" /add /domain
   ```

3. Run the focused Splunk search and confirm Event ID 4720 is present.
4. Record the destination host, creating account, new account name, and timestamp.
5. Remove the controlled account:

   ```cmd
   net user SOC-Test-4720 /delete /domain
   ```

---

## Validated Result

The detection was validated in the Enterprise Splunk SOC Lab with the following observed values:

- Event ID: 4720
- Host: DC01
- Creating account: Administrator
- New domain account: SOC-Test-4720

---

## Investigation Guidance

1. Confirm whether the account creation was authorized through an approved identity-management process.
2. Identify the administrator, service, or system that created the account.
3. Review the new account’s group memberships, privileges, description, logon restrictions, and password settings.
4. Check for rapid additions to privileged groups or subsequent authentication from unusual systems.
5. Correlate with account-management events, logons, PowerShell, process creation, and remote administration activity.
6. Disable or remove unauthorized accounts and escalate the incident.

---

## False Positives

Legitimate Event ID 4720 activity may be generated by:

- Help desk and identity-management workflows
- New employee or contractor onboarding
- Service-account provisioning
- Automated deployment systems
- Authorized lab testing

Reduce noise by baselining approved account creators, naming conventions, ticket references, and provisioning windows.
