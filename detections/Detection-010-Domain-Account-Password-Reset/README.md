# Detection 010 – Domain Account Password Reset

## Objective

Detect attempts to reset Active Directory account passwords by monitoring Windows Security Event ID 4724. Unauthorized password resets may indicate account takeover, persistence, privilege abuse, or attempts to deny access to legitimate users.

---

## MITRE ATT&CK

| Tactic | Technique |
|---|---|
| Persistence, Privilege Escalation | T1098 – Account Manipulation |

---

## Data Source

- Windows Security Event Log
- Event ID 4724
- Active Directory domain controllers

---

## Detection Logic

Monitor Event ID 4724 and identify both the account performing the password reset and the target account. Prioritize privileged targets, resets performed by unexpected administrators, repeated resets, and changes occurring outside approved support workflows.

---

## Splunk Search

```spl
source="WinEventLog:Security" EventCode=4724
| rex field=Message "Subject:\s+Security ID:[^\r\n]+\s+Account Name:\s+(?<ResetBy>[^\r\n]+)"
| rex field=Message "Target Account:\s+Security ID:[^\r\n]+\s+Account Name:\s+(?<TargetAccount>[^\r\n]+)"
| table _time host ResetBy TargetAccount
| sort -_time
```

### Focused Validation Search

```spl
source="WinEventLog:Security" EventCode=4724
| rex field=Message "Subject:\s+Security ID:[^\r\n]+\s+Account Name:\s+(?<ResetBy>[^\r\n]+)"
| rex field=Message "Target Account:\s+Security ID:[^\r\n]+\s+Account Name:\s+(?<TargetAccount>[^\r\n]+)"
| search TargetAccount="SOC-Test-4720"
| table _time host ResetBy TargetAccount
| sort -_time
```

---

## Validation Procedure

1. Use the controlled domain account created during Detection 008 testing.
2. Search for Event ID 4724 on the domain controllers.
3. Filter the results to the controlled target account.
4. Confirm the event identifies the resetting account, target account, host, and timestamp.
5. Preserve the focused result and screenshot as validation evidence.

The controlled account was removed after testing.

## Validated Result

The detection was validated in the Enterprise Splunk SOC Lab with the following observed values:

- Event ID: 4724
- Host: DC01
- Password reset by: Administrator
- Target account: SOC-Test-4720

---

## Investigation Guidance

1. Confirm whether the reset was authorized through a help desk, identity-management, or administrative workflow.
2. Determine whether the resetting account normally performs password resets.
3. Assess the target account’s privileges, group memberships, and recent authentication history.
4. Review nearby account changes, failed logons, successful logons, and privilege assignments.
5. Correlate with PowerShell, process creation, remote administration, and ticketing data.
6. Secure affected accounts and escalate unauthorized password resets.

---

## False Positives

Legitimate Event ID 4724 activity may be generated by:

- Help desk password-reset requests
- Administrator maintenance
- New account provisioning
- Identity-management automation
- Authorized lab testing

Reduce noise by baselining approved reset operators, ticketed workflows, service accounts, and expected operating hours.
